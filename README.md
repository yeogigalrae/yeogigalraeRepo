# 여기갈래 - 축제 정보 제공 어플리케이션


## 프로젝트 진행 기간
2023.11.01(수) ~ 2023.12.18(월)
모바일 프로젝트


## 여기갈래 - 배경
코로나이후 사람들의 놀거리를 찾는 움직임이 증가함에 따라 축제를 찾는 사람의 수도 자연스레 증가하게 될것으로 보인다.

손쉽게 축제 정보 실시간으로 제공받고 사람의 성향, 선호도의 따라서 축제를 추천할 수 있는 어플리케이션을 제작하기로 하였습니다.

## 여기갈래 - 주요기능
- 축제 정보 제공
- 축제 추천
- 축제별 실시간 채팅
- 축제별 감정분석
- 지도 검색

## 개발 환경
### Backend 
- Nodejs
### Frontend 
- React Native
### Database 
- MariaDB
### tool 
- Git
- Github Desktop
- Notion
- Visual Studio Code
